# Incident Response RACI Matrix
## Objetivo
Definir papéis e responsabilidades durante a resposta a incidentes de segurança da informação.

# Legenda
- R = Responsible (Executa)
- A = Accountable (Responsável Final)
- C = Consulted (Consultado)
- I = Informed (Informado)


# Matriz RACI
# Detectar Incidente
- SOC: R
- Security Manager: A
- Infraestrutura: I
- Jurídico: I
- DPO: I
- Executivos: I


# Classificar Incidente
- SOC: R
- Security Manager: A
- Infraestrutura: C
- Jurídico: I
- DPO: I
- Executivos: 


# Conter Incidente
- SOC: R
- Security Manager: A
- Infraestrutura: R
- Jurídico: I
- DPO: I
- Executivos: I


  # Investigar Incidente
- SOC: R
- Security Manager: A
- Infraestrutura: C
- Jurídico: I
- DPO: I
- Executivos: I
