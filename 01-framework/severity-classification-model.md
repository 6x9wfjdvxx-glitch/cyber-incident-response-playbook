# Severity Classification Model
## Objetivo
Definir níveis padronizados de severidade para incidentes de segurança da informação.

## Severidade 1 - Crítica
Critérios:

- Sistemas críticos indisponíveis.
- Impacto significativo ao negócio.
- Dados sensíveis comprometidos.
- Necessidade de acionamento do comitê de crise.
## Severidade 2 - Alta
Critérios:

- Múltiplos sistemas afetados.
- Possível comprometimento de dados.
- Impacto operacional relevante.
## Severidade 3 - Média
Critérios:

- Impacto limitado.
- Sistemas não críticos afetados.
- Baixo risco de propagação.
## Severidade 4 - Baixa
Critérios:

- Sem impacto operacional.
- Tentativas bloqueadas.
- Incidentes de baixo risco.
## Referências
- NIST SP 800-61 Rev. 3
- ISO 27035
