# Incident Response Reference Architecture
## Objetivo
Definir uma arquitetura de referência para detecção, resposta e recuperação de incidentes de segurança.

## Fontes de Dados
- Endpoints
- Servidores
- Aplicações
- Cloud
- E-mail
- Identidade

## Coleta de Eventos
Ferramentas:

- Microsoft Defender
- Microsoft Defender for Cloud
- Azure Monitor
- Microsoft Entra ID

## Correlação de Eventos
Ferramenta:

- Microsoft Sentinel
- Objetivos:

- Detectar ameaças
- Correlacionar eventos
- Priorizar alertas

## Resposta Automatizada
Ferramentas:

- Microsoft Sentinel
- Logic Apps
Exemplos:

- Bloqueio de conta
- Isolamento de dispositivo
- Notificações automáticas

## Processo de Resposta
- Detecção
- Análise
- Contenção
- Erradicação
- Recuperação
- Lições Aprendidas

## Comunicação
Participantes:

- SOC
- Security Manager
- Infraestrutura
- Jurídico
- DPO
- Executivos

## Indicadores
- MTTD
- MTTR
- Incidentes por Categoria
- Incidentes por Severidade

## Referências
- NIST SP 800-61 Rev. 3
- Microsoft Sentinel
- Microsoft Defender
