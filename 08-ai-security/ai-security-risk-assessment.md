# AI Security Risk Assessment
## Objetivo
Avaliar riscos relacionados ao uso de Inteligência Artificial Generativa em ambientes corporativos.

# Principais Riscos
Vazamento de Dados
Risco:

- Compartilhamento de informações sensíveis em prompts.
Impacto:

- Exposição de dados corporativos.
# Prompt Injection
Risco:

- Manipulação de instruções fornecidas ao modelo.
Impacto:

- Resultados incorretos ou inseguros.
# Uso Não Autorizado
Risco:

- Utilização de ferramentas de IA sem aprovação.
Impacto:

- Perda de controle sobre informações.
# Alucinação
Risco:

- Respostas incorretas apresentadas como verdadeiras.
Impacto:

- Tomada de decisão inadequada.

# Controles Recomendados
- Treinamento de usuários.
- Classificação de informações.
- Monitoramento de uso.
- Políticas de IA.
- Revisão humana das respostas.
