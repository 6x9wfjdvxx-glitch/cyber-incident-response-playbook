# Microsoft Copilot Security
## Objetivo
Apresentar recomendações de segurança para utilização do Microsoft Copilot em ambientes corporativos.

## Principais Riscos
Compartilhamento de Informações Sensíveis
Risco:

- Exposição de dados corporativos em prompts.
Impacto:

- Vazamento de informação.
Acesso Excessivo
Risco:

- Usuários acessarem dados que não deveriam visualizar.
Impacto:

- Exposição de informações internas.

## Respostas Incorretas
Risco:

- Utilização de informações imprecisas.
Impacto:

- Tomada de decisão equivocada.

##Controles Recomendados

- Classificação da informação.
- Controle de acesso baseado em função.
- Sensitivity Labels.
- Data Loss Prevention (DLP).
- Monitoramento contínuo.
- Treinamento de usuários.

## Boas Práticas
- Validar respostas antes da utilização.
- Não inserir dados confidenciais sem autorização.
- Utilizar contas corporativas.
- Registrar exceções e riscos.
