# Security KPIs
## Objetivo
Definir indicadores-chave para monitorar a eficiência do processo de resposta a incidentes.

## MTTD - Mean Time to Detect
Tempo médio necessário para detectar um incidente.

Objetivo:

- Reduzir o tempo de detecção.
## MTTR - Mean Time to Respond
Tempo médio necessário para responder a um incidente.

Objetivo:

- Melhorar a velocidade da resposta.
## Tempo de Recuperação
Tempo necessário para restaurar os serviços afetados.

Objetivo:

Minimizar o impacto no negócio.
## Incidentes por Severidade
Monitorar:

- Severidade 1
- Severidade 2
- Severidade 3
- Severidade 4
Objetivo:

Identificar tendências.
## Incidentes por Categoria
Monitorar:

- Phishing
- Ransomware
- Data Breach
- Conta Privilegiada
- Cloud Security
Objetivo:

Priorizar investimentos.
## Taxa de Recorrência
Quantidade de incidentes repetidos.

Objetivo:

- Reduzir reincidências.

## Referências
- NIST SP 800-61 Rev. 3
- ISO 27035
