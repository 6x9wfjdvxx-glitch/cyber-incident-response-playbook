# Incident Response Lifecycle
## Objetivo
Definir as fases do processo de resposta a incidentes de segurança da informação.

## Fase 1 - Preparation
Preparação da organização para responder incidentes.

Exemplos:

- Políticas
- Procedimentos
- Treinamentos
- Ferramentas
- Equipes

  
## Fase 2 - Detection
Identificação do incidente.

Exemplos:

- SIEM
- Microsoft Sentinel
- EDR
- Alertas de usuários

  
## Fase 3 - Analysis
Análise do incidente.

Objetivos:

- Confirmar incidente
- Identificar impacto
- Determinar severidade


## Fase 4 - Containment
Conter a ameaça.

Exemplos:

- Isolamento de hosts
- Bloqueio de contas
- Bloqueio de IPs


## Fase 5 - Eradication
Remover a ameaça.

Exemplos:

- Remoção de malware
- Correção de vulnerabilidades
- Revogação de acessos


## Fase 6 - Recovery
Restabelecer operação normal.

Exemplos:

- Restaurar backups
- Validar integridade
- Retornar sistemas à operação


## Fase 7 - Lessons Learned
Identificar oportunidades de melhoria.

Exemplos:

- Revisão de controles
- Atualização de procedimentos
- Treinamentos adicionais


## Referências
- NIST SP 800-61 Rev. 3
- ISO 27035
