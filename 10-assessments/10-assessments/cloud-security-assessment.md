# Cloud Security Assessment

Avaliar controles de segurança em ambientes de nuvem.

## Governança
Avalie de 1 a 5:

- Políticas Cloud
- Gestão de Riscos
- Controle de Custos
- Conformidade

## Identidade e Acesso
Avalie de 1 a 5:

- MFA
- PIM
- RBAC
- Revisão de Acessos

## Proteção de Dados
Avalie de 1 a 5:

- Criptografia
- DLP

## Monitoramento
Avalie de 1 a 5:

- Logs
- Alertas
- SIEM
- Dashboards

## Resposta a Incidentes
Avalie de 1 a 5:
